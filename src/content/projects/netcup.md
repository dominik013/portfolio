My public fork of the **netcup DNS provider module for Caddy**. The upstream module manages DNS records through the netcup API and can be used for ACME DNS challenges.

This is a fork of [caddy-dns/netcup](https://github.com/caddy-dns/netcup). The original project and its authors are credited upstream.
