A static website for **garage by tom**, bringing the restaurant's weekly menu, food menu, and directions together in one place.

The site is built with Astro and published on Cloudflare Pages. Menus are stored as structured content in GitHub and can be edited through Pages CMS. An update creates a commit, which triggers a new site build.

## What is inside

- A homepage, weekly menu, full food menu, and directions page.
- Content validation for prices, categories, and weekdays before publication.
- Locally hosted images and fonts, with a map loaded near the directions section.
- A static deployment with no application server or database to maintain.

The linked site is an MVP preview; some business details and menu content are still awaiting final confirmation.
